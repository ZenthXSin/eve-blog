# Kotlin 模组教程

> 用 Kotlin 写 Mindustry mod 的工程实践与配套工具。基线：原版 Mindustry v159.7。

## 内容

- [kt-annotations](./kt-annotations/) —— Mindustry 注解处理器的 Kotlin 复刻（Entity/Struct/Remote/Logic/Load/Assets 六大注解）
- [arc-ui-dsl](./arc-ui-dsl/) —— Arc UI 的组合式 Kotlin DSL（v1.0.0，覆盖 arc v159.7 全部 18 控件 + Mindustry 特有控件）
